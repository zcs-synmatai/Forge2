# 工作流编辑页面：当前版与 V1

## 当前版交互要求

- 左侧研究 Copilot 支持收起、展开，并保留对话内容与收起状态；收起后右侧区域扩展。
- 右侧上方始终保留宏观建模窗口和方块基体／填料可视化。选择工作流中的计算、宏观、结果等节点不会切换成其他类型预览。
- 暂时移除“几何、网格、材料与界面、边界条件、求解设置”这排分组入口。
- 工作流标题栏支持“全屏／恢复”切换。全屏时保留主菜单与 AI 对话栏（含收起状态），其余页面区域由工作流铺满；支持 Esc 恢复，节点参数弹窗与画布操作仍然可用。
- 右侧下方为无限工作流画布，支持开始、微观建模、微观物性计算、宏观建模、计算调度、结果呈现、结束节点。
- 每种材料对应独立的微观建模节点，模型可以连接多个物性计算节点，支持热导率、密度、黏度、弹性模量的参数演示。
- 材料名称按钮选择材料后，快捷菜单紧贴该按钮；在模型内点击填料选择材料时，快捷菜单显示在点击位置附近。
- 选择材料时同步选择微观建模节点；选择微观建模或对应物性计算节点时，在宏观视图高亮对应材料。
- 材料菜单中的“微观建模”打开分子示意弹窗；节点“打开配置”使用弹窗配置其参数，保存后下游结果需重新检查。分子示意不代表材料真实化学结构。
- 工作流必须有且仅有一个开始节点和一个结束节点，按阶段正向连接，且所有节点都位于从开始到结束的完整路径上。环路、断开的分支、无出口节点及缺少阶段均阻止运行并提示定位。
- 已有工作流自动拆分微观建模与物性计算、补齐开始和结束节点，历史执行快照保留；当前版使用独立本机草稿，V1 归档保持原状。

当前版入口为 `/multiscale/workflows/:workflowId/edit`。V1 入口仍在“演示说明 → 工作流编辑 V1”。

## V1 归档交互要求

以下为 V1 版本原有的工作流编辑要求；仅在 V1 入口展示。

以本轮用户确认为准：系统节点只有 **微观模拟、宏观建模、计算调度、结果呈现** 四种类型。TIM 材料和圆管流动是宏观模型的案例，不是平台的节点分类。原六节点 TIM 拆分方案已被本版取代。

## 页面与交互范围

从工作流列表进入编辑页，页面布局沿用参考项目 D:\Agent4\prototype\SynMatAI 的计算模拟工作台与品牌紫 v4。保留全局栏、侧栏、顶部名称及运行操作、左侧研究 Copilot、右上依赖图、右下常驻节点配置。原型代码独立保存在本项目 prototype 子目录，运行时不依赖参考项目。

无限画布交互只作用于依赖图矩形区域。复用任务工作台画布的平移、指针锚定缩放、框选多选、节点拖动、吸附、端口连接、缩略图和撤销重做。面板外的布局保持不变。节点不显示悬浮属性弹窗；选中即更新下方配置，双击或 Enter 可定位配置区域。

画布左下提供缩小、缩放百分比（点击恢复 100%）、放大、适应画布、当前节点定位与自动布局。工具条与创建工具、缩略图错开，自动布局只调整位置与路由，不修改四阶段依赖。

## 四种节点与连线

1. 微观模拟：引用已有微观模拟任务，提供结构化结果或数据引用。保留已有任务入口，不重复建设微观模拟表单。
2. 宏观建模：接收微观模拟数据，配置宏观模型。几何、网格、材料、物性提取映射、边界条件与模型设置都属于该节点内部。
3. 计算调度：接收宏观模型，展示调度策略、计算资源、并行核数、失败重试等独立配置。原型仅本地演示依赖执行，不声称已经实现真实资源调度。
4. 结果呈现：接收计算调度输出，展示报告、文本结论、生成状态及作业与结果入口。

仅允许相邻阶段正向连接：

微观模拟 → 宏观建模 → 计算调度 → 结果呈现

不允许同阶段、反向、跨阶段、自连接和循环。结果呈现是末端节点。同一类型可以有多个节点；多个上游节点可连接同一个下一阶段节点，不应相互覆盖。错误提示明确指出允许的目标阶段。画布不再以 TIM 热导率、网格或微观轨迹的字段单位决定阶段之间能否连线。具体物性字段与单位属于宏观模型内部配置和案例校验。

新增菜单仅显示上述四种节点。新宏观节点默认通用模型，不默认假设 TIM。新建工作流支持空白、通用四阶段、TIM 案例、圆管流动案例。案例模板都使用四阶段结构。

## 常驻节点配置

选择微观节点时，预览区显示可拖动旋转、滚轮缩放、重置视角及切换标签的分子球棍模型，并提供“修改分子”。修改面板允许更换示例结构、编辑名称、元素、坐标和化学键、增删原子与键，支持实时预览。取消不保存，应用后更新当前节点并使下游结果过期，保留历史快照，支持撤销。当前分子是本地原型结构示意，尚未关联真实任务结构文件，不执行化学有效性校验或几何优化。

保留模型与配置 / 变更记录、节点状态、运行此节点、删除、输入来源和校验区。配置字段随选中类型切换。修改节点使相关下游输出过期，历史运行快照独立保留。

宏观模型可选择通用模型、颗粒填充 TIM 案例、简单圆管流动案例。切换案例保留各自已编辑参数，不改变节点类型或阶段连接。

通用模型提供模型名称和说明，后续接入具体模型与算法契约。不展示虚构的物理计算结果。

TIM 案例保留原模型预览与设置分组：
- 几何：基体长宽高、离散非接触颗粒、分布、随机种子、最小间隙、目标填充率（待算法确认输入）。
- 网格：网格尺寸及演示几何检查。
- 材料与界面：基体 / 填料热导率、界面热阻、数据来源。物性提取与映射作为模型内部配置扩展。
- 边界条件：方向、冷热端温度、固定绝热侧面。
- 模型设置：当前案例使用 Forge FVM V1 三维稳态纯导热。此限制只属于该案例。
- 三维几何示意可旋转、缩放、重置、显示网格和高亮；不得称为真实网格或求解结果。

流动案例保留圆管示意、尺寸、密度、已有流变模型参数、温度、入口与出口配置。具体支持范围以算法契约为准。

计算调度配置与宏观模型分离，原型中提供按依赖执行、本地演示资源、核数和重试次数。真实服务、队列和重试引擎待接入。

结果呈现提供 PDF 演示报告和文本结论。报告依据本次执行快照的模型案例选择内容，通用模型不能套用 TIM 数值。报告失败与计算失败分别展示；未完成时提示等待上游结果。

## 保存、运行与旧数据迁移

按 workflowId 隔离本地草稿、相机与节点位置。修改后需重新检查；运行工作流按四阶段依赖顺序生成独立快照，并提供进度、取消和查看本次作业。实际算法尚未接入，所有执行与报告明确为原型演示。

旧的性质提取、参数映射、几何网格、TIM / 流动求解及结果报告结构迁移到四类节点：几何和案例参数合入宏观模型，增加独立计算调度节点。保留原定义备份、原历史记录和原执行快照，迁移后重新校验。

## 验收

- 编辑页仍为左侧 Copilot、右上局部画布、右下配置，节点无悬浮弹窗。
- 新增菜单只有四类节点；所有相邻正向组合可连接，反向、同阶段、跨阶段连接被明确拦截。
- 通用、TIM 与流动模板使用同一套阶段连线；TIM 只是案例。
- 选中四类节点分别显示对应配置；案例切换不丢原参数。
- 旧草稿迁移后保留备份和历史快照，四阶段可重新检查并演示运行。
- 列表节点数、模板说明及作业结果入口与新结构一致。

### TIM 双填料演示

TIM 默认由基体材料、球状填料、片状填料组成；片状使用有厚度的薄片实体示意，支持模型点击选材、高亮和微观建模弹窗。材料管理可设置球状／片状形貌。已有 TIM 草稿首次补齐双填料配置并保留原材料与节点标识；已有第二种填料则作为片状展示，后续用户设置不再被初始化覆盖。每种材料都有独立微观建模与物性计算节点，形成三条输入分支；默认共 11 个工作流节点。历史快照不修改。


### 演示流程调整（覆盖双填料默认展示）

默认展示基体＋一种球状填料及两条材料分支（9 个节点）；预览材料栏提供“添加材料”，点击后新增／启用片状填料，同步增加微观建模与物性计算分支（11 个节点）。添加后入口变为材料管理。旧双填料演示草稿首次转为该流程，第二种填料保留在未分配清单中，历史执行快照不变；后续已添加的材料不会因刷新再次隐藏。

画布节点隐藏长内部编号，顶部使用独立的类型标签与状态标签。“已过期”在节点卡片中显示为“待更新”，不改变内部执行状态；避免类型、状态和编号相互挤压。


### 暂时移除 Copilot

当前工作台移除左侧 Copilot 对话栏、收起／展开入口及画布中的对话引用入口。建模和工作流区域占满主菜单右侧宽度，全屏／恢复继续可用；历史对话数据不删除，V1 归档不变。


### 结构与材料库分离

材料管理以模型结构为主：先定义基底、材料1、材料2等结构，再通过材料库下拉选择或搜索浏览指定其材料。球状／片状、显示颜色、名称属于结构；材料库材料名、分子数据标识、示意结构及物性保存在独立引用记录中，只读显示，多个结构可使用同一材料库记录。形貌与颜色变化不修改材料库。新增结构尚未选择材料时禁止应用；取消不影响当前模型。

预览改为“模型结构”，每个结构显示名称、对应材料和形貌。工作流按结构维持微观建模与物性计算分支，材料重选更新引用并标记下游待更新。已有结构／节点标识和历史快照保留；原模型自定义材料迁移时保留名称与物性。材料库数据目前为原型示例，分子示意不是实际材料真实结构。


### 微观建模双栏弹窗

微观建模弹窗采用左侧二维分子式编辑、右侧三维球棍预览。二维区域提供选择移动、添加原子、元素选择、删除、单／双／三键、苯环示例、清空、撤销重做、氢原子显示和分子名称编辑；三维预览同步更新，支持旋转、缩放、重置视角及标签。分子式随原子数据更新，不提供完整 SMILES 解析或化学价校验。

修改先保存在弹窗草稿，取消不应用；应用后只更新当前结构对应微观模型，使下游需更新，不改写材料库分子数据。示例结构不代表真实材料分子。V1 弹窗保持原样。


### 应用类型与初始建模（2026-11-03）

新建模拟任务的“应用类型”按 TIM材料、挤出模拟、简单圆管示例、空白工作流排序。TIM材料沿用基底与填料交互；空白工作流保留工具与基础节点，不创建几何或材料结构。

挤出模拟初始化四个独立管段结构，按圆柱、圆锥过渡段、圆柱、圆锥过渡段连续连接。圆柱可编辑长度、半径，圆锥过渡段可编辑长度、入口半径、出口半径；修改后自动重排管段位置并同步接口尺寸。模型选择、结构标签、尺寸快捷菜单和右侧结构尺寸入口联动，材料配置与对应的微观建模及物性计算节点绑定。

简单圆管示例仅初始化一个圆柱管段，可编辑长度和半径。挤出和简单圆管使用管段视图，不展示 TIM 基底或颗粒。所有尺寸和材料配置在本地保存，保持原型演示性质。


### 挤出模式整体材料与三维坐标（2026-11-03，覆盖上节材料绑定规则）

四段挤出管路只作为几何结构编辑尺寸，整体共用一种材料。统一配置材料和物性参数，并对应一个材料计算节点；不再为四段建立各自的材料、微观模型或物性计算分支。已有四分支任务迁移为整体材料，保留原尺寸、历史执行快照和迁移备份。

管路视图采用固定正交缩放基准，拖动只旋转视角，不随投影范围自动缩放或重新居中。滚轮与缩放按钮仍可主动缩放，适应模型可重置视图。显示 XYZ 三维坐标、对应长度单位及数值标尺，坐标网格、标尺位置和方向指示器与模型共用三维旋转投影；刻度文字保持可读。

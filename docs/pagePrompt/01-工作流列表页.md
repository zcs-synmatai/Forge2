# 工作流列表页原型提示词

请设计并生成一个中文、桌面优先、可交互的“计算工作流”列表页。它属于通用材料研发 Web 系统，是进入工作流编排的默认入口。用户需要快速找到已有流程、判断是否可以运行、继续编辑或查看最近的结果报告与仿真结论。

优先按 [整体导航与原型约定](./00-整体导航与原型约定.md) 实现；功能依据为 [需求简版](../跨尺度模拟系统需求简版.md)。请直接交付页面原型，避免生成营销首页或项目协作系统。

## 布局

```text
全局栏：材料研发平台                              账户入口
系统导航 │ 计算工作流                         新建工作流
         │ 创建和编排微观模拟与宏观仿真计算
         │ 搜索工作流名称   类型筛选   定义状态   最近执行状态
         │ 工作流列表表格
         │ ...
         │ 共 N 条                           分页 / 每页条数
```

页头主标题“计算工作流”，副文案“连接微观模拟与宏观仿真，配置并执行计算流程”。右侧只保留一个主按钮“新建工作流”。不显示创建项目、邀请成员、审批、项目选择器或资源管理。

## 筛选区

- 名称搜索，输入提示“搜索工作流名称”。
- 计算类型：全部、TIM 导热、流动。
- 定义状态：全部、草稿、可运行、需更新。
- 最近执行：全部、尚未运行、排队中、运行中、成功、失败、已取消。
- 筛选变化后保留当前筛选值、重置到第一页；支持清空筛选。

定义状态说明编辑内容是否就绪，最近执行说明某次运行的情况，两个字段独立展示。

## 列表字段与操作

| 列 | 展示要求 |
| --- | --- |
| 工作流名称 | 可点击打开工作台；下一行显示一句用途说明 |
| 计算类型 | TIM 导热或流动，小标签 |
| 节点数 | 数字与“个节点”；不显示为任务进度 |
| 定义状态 | 草稿、可运行、需更新 |
| 最近执行 | 状态文字、执行时间；未运行显示“尚未运行” |
| 更新时间 | 本地时间，支持排序 |
| 操作 | 主文字操作“编辑”；有记录时显示“查看作业”；更多菜单只放“复制”“重命名” |

名称列占较大宽度，时间和节点数对齐，状态列避免拥挤。工作流正在运行时，编辑产生后续定义变更，不修改正在运行的快照；原型使用解释提示说明。

首次至少展示以下 5 条记录，完整 ID 和状态按公共约定：

1. 颗粒填充 TIM 导热评估：TIM、6 节点、可运行、最近执行成功。
2. 圆管非牛顿流动计算：流动、5 节点、可运行、最近执行运行中。
3. 填料取向对导热的影响：TIM、6 节点、草稿、尚未运行。
4. 变径圆管压降分析：流动、5 节点、草稿、最近执行失败。
5. 界面热阻敏感性算例：TIM、6 节点、需更新、最近执行成功但使用旧输入。

所有记录为演示数据，页面角落使用轻量“原型演示”标识。最近成功与当前需更新同时存在时应清晰解释，而非互相覆盖。

## 新建工作流

点击“新建工作流”打开轻量弹窗：

- 名称，必填，默认“未命名工作流”，可编辑。
- 起始方式：空白工作流、TIM 导热示例、简单圆管流动示例。
- 一句说明“微观计算将引用系统已有分子库和模拟能力”。
- 底部“取消”“创建并编辑”。

创建后进入独立工作台 `/multiscale/workflows/:workflowId/edit`。示例带入节点和演示参数，但运行前必须经过校验；空白流程进入空画布。

## 交互与状态

- 点击名称或“编辑”：进入工作台并选中默认宏观节点；空白流程不预选节点。
- 点击“查看作业”：进入 `/multiscale/runs?workflowId=...&runId=...`，定位该次执行。
- 点击复制：打开名称确认弹窗，生成“原名称 副本”，保留节点和配置，清空执行记录，提示“已复制，打开编辑”。
- 点击重命名：校验非空后更新名称。
- 无工作流：显示“还没有计算工作流”和“新建工作流”。
- 搜索无匹配：显示“未找到匹配的工作流”和“清空筛选”。
- 加载中：表格骨架；加载失败：显示具体重试入口。
- 最近失败状态可查看简短原因，并提供“定位到工作台”。
- 不增加批量删除、项目归档、权限设置或模板管理功能。

## 验收路径

搜索“导热”能筛出匹配记录；切换类型能过滤列表；新建 TIM 示例能进入工作台；运行中的记录能进入对应作业；复制后的流程没有历史作业。所有可见按钮均有合理反馈，键盘焦点和状态文本可辨认。

# 作业与结果页原型提示词

请生成中文“作业与结果”页面，以运行记录、本次仿真结果报告文件和已经总结好的文本结论为核心。用户进入页面后应快速了解执行状态、阅读本次仿真结论，并预览或下载结果报告。

依据为 [整体导航与原型约定](./00-整体导航与原型约定.md) 和 [需求简版](../跨尺度模拟系统需求简版.md)。本轮结果展示按用户最新范围简化：报告文件与文本结论，需求简版中的复杂场结果查看功能暂不用于本轮原型。

## 导航与视觉

整体视觉完整迁移自 `D:\Agent4\prototype\SynMatAI` 的当前品牌紫 v4。实现前读取 `docs/project-context.md`、`docs/design.md`、`apps/web/index.html`、`apps/web/src/styles/main.css` 及其导入样式。报告阅读交互可复用 `apps/web/src/features/workflow/task-report.js`，解除项目和阶段上下文耦合。复用侧栏、顶部栏、页签、按钮、状态、SVG 图标及文档阅读样式，不另做报告中心的视觉体系。

全局栏、侧栏宽度和断点按源项目有效 CSS。四个一级菜单依次为“分子库”“微观模拟”“计算工作流”“作业与结果”，当前选中“作业与结果”。不设置“跨尺度模拟”父级，也不迁入源项目的项目阶段导航。

工作流编排工作台不出现在菜单中，通过工作流列表点击名称或“编辑”进入。本页提供“返回工作台”，携带工作流和节点上下文。

参考尺寸 1440 × 900。品牌主色 #5F36FC，基础画布 #F5F6F8、白色面板、正文 #243044、次文字 #5E6B7D、边框 #E3E7EE；局部覆盖、字号、圆角、间距、阴影与状态色沿用源 CSS。字体 Segoe UI / Microsoft YaHei，结论采用源文档阅读区的行高，避免大面积数字卡片。使用轻量“原型演示”标识。

## 页面布局

左侧为约 280 像素宽的执行记录列表，可收起；右侧为所选执行内容。页头展示工作流名称、状态、执行 ID、提交时间和返回工作台操作。

页签依次为“结果报告”“日志与诊断”“输入快照”。默认打开结果报告，依次展示：

1. 本次仿真结论：已经总结好的可读文本，支持复制。
2. 仿真结果报告文件：文件信息、生成状态、预览和下载。
3. 报告正文预览：文档式阅读区域。

不提供三维场结果查看、色标、切面、选点、轨迹播放器或复杂指标分析区。主要数值放在结论和报告表格中。

## 执行记录

支持搜索工作流名称或执行 ID、筛选计算类型及执行状态。每条显示名称、提交时间和状态。运行中的显示当前阶段和完成节点数，不编造预计完成时间。

同一工作流的每次执行都有独立结果。从工作台带 runId 进入时默认定位该次执行，建议路由为 /multiscale/runs?workflowId=...&runId=...，内部前缀不代表菜单层级。

执行状态：排队中、运行中、成功、失败、已取消。报告状态：待生成、生成中、已生成、生成失败。两者独立展示。

“本次仿真”指当前工作流的某次执行，不新增项目对象或项目选择器。

## 本次仿真结论

位于结果报告页签顶部，标题“本次仿真结论”。显示生成时间、对应执行 ID 和“复制结论”。使用自然段，不设计问答框或“让 AI 分析”按钮，不展示生成过程。

结论包含对象与工况、主要发现、关键数值、适用条件。没有目标阈值或对照算例时，不输出“达标”“最优”“提升了多少”等判断。

TIM 成功场景采用以下完整示例正文：

本次对颗粒填充复合材料样本进行了 Z 方向稳态纯导热计算。在热端 80 °C、冷端 20 °C、侧面绝热的设定下，得到样本有效热导率为 2.46 W/(m·K)，实际填充率为 18.7%。以上结果反映本次几何尺寸、颗粒分布、材料参数和界面热阻条件下的样本导热表现，可用于本次工况的结果记录。若用于表征材料代表值，还需进一步验证样本尺寸与填充方式的影响。

正文下标注“原型演示结论”。

流动作业运行中显示“本次仿真尚未完成，完成后将展示总结结论”。不借用历史结果。可通过演示状态切换查看以下成功文案：

本次基于设定的广义牛顿流变模型完成圆管稳态流动计算，得到压降 12.8 kPa、出口平均流速 0.42 m/s、体积流量 1.98 L/min。结果适用于本次流道几何、边界条件以及所输入流变模型的有效剪切速率范围。由于未设置目标压降或对照工况，本次结论仅记录计算结果，不作性能达标判断。

流动演示数据按直径 10 mm 圆管构造，不能作为真实算法输出。具体流变参数由真实任务提供。

## 仿真结果报告文件

结论下方展示报告文件，例如“颗粒填充TIM导热评估_结果报告.pdf”。包含文件图标、名称、格式、大小、生成时间、报告状态、“预览”“下载报告”。

原型以 PDF 演示，实际报告格式由接口确认；不能宣称 Forge FVM 已原生输出 PDF。报告根据本次计算结果整理，区别于原始求解文件。

点击预览，在页面下方或宽抽屉打开文档，支持滚动、页码和下载。若工具不支持真实 PDF，使用文档式 HTML 预览并标注“报告预览（演示）”。下载可生成演示 PDF；不支持时下载完整 HTML 报告并标注实际格式，不能将 HTML 伪装为 PDF。

报告至少包含：

1. 报告名称、工作流、执行 ID、计算类型和生成时间。
2. 仿真目的和计算对象。
3. 输入摘要：几何、微观结果引用、材料、界面和边界条件。
4. 计算方法、算法版本和执行信息。
5. 主要结果表：指标、数值、单位、说明。
6. 仿真结论，与页面顶部结论一致。
7. 适用范围及结果条件说明。

默认以正文和表格构成报告，不要求云图或三维图。报告下载与当前执行绑定，切换执行后不能继续下载上一条记录的报告。

## 辅助页签

“日志与诊断”：按时间显示消息，支持按节点筛选、搜索和下载。失败示例为“出口面未绑定，几何校验未通过”，提供“定位到工作台”，下游显示未执行。

“输入快照”：只读展示本次工作流版本、节点输入、微观结果引用、映射、几何、边界和求解器版本。后续编辑不修改历史快照和报告。

原始文件如需下载，在辅助页签底部使用折叠入口，格式由算法返回，不建设通用文件浏览器。

页头按状态提供“取消运行”“返回工作台修正”或“返回工作台”。未开始或未结束的时间显示“—”，不填成零时长。

## 异常与等待

- 排队或运行中：报告和结论待生成，没有虚构成功结论。
- 求解成功、报告生成中：执行仍为成功，显示“报告整理中”“结论整理中”。
- 报告生成失败：展示原因及“重新生成报告”，只重试报告整理，不重新求解。
- 报告已生成、结论缺失：报告仍可下载，结论显示“暂未生成”，两部分不相互阻塞。
- 求解失败或已取消：只展示过程说明与日志；已有诊断文件标记为“诊断记录”。
- 报告预览失败：提示下载查看，保持下载可用。
- 当前定义已更新：历史报告保留，提示“本报告基于历史执行输入”，可打开当前工作流。
- 无作业或筛选无结果：提供前往计算工作流或清空筛选的操作。

## 验收路径

选择成功 TIM 作业，阅读和复制结论、预览和下载报告；切换运行中作业显示等待；切换失败作业定位工作台；历史报告显示输入已更新；报告生成失败时仅重试报告生成；返回工作台恢复工作流和节点上下文。整个结果页不出现三维查看或复杂结果分析控件。

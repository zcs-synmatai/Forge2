# 整体导航与原型约定

## 使用方式

本目录用于向 AI 原型工具提交页面生成任务。先提供本文件，再提供目标页面的提示词。三个页面提示词也包含关键公共约定，可以单独使用。

依据：[跨尺度模拟系统需求简版](../跨尺度模拟系统需求简版.md)。算法依据：[Forge FVM V1 算法边界](../Forge--FVM%20V1算法边界.docx)。本轮原型按用户最新范围：菜单平铺；结果以报告文件和已总结的文本结论呈现。需求文档中复杂场结果查看相关描述暂不用于本轮原型。

| 文件 | 用途 |
| --- | --- |
| 01-工作流列表页.md | 生成工作流的创建、搜索、筛选和继续编辑入口 |
| 02-工作流编排工作台.md | 生成独立的工作流编辑页面，借鉴用户参考图的布局 |
| 03-作业与结果页.md | 生成运行记录和结果查看的一体化页面 |

## 设计迁移来源与优先级

本项目整体设计风格完全迁移自 `D:\Agent4\prototype\SynMatAI` 当前源码的品牌紫 v4。不是仅参考配色，不重新设计一套类似风格。页面布局组件、字体、图标、边距、圆角、边框、菜单、按钮、表单、页签、弹窗、提示反馈及响应式行为均优先复用源项目。

工作流编排页必须从源项目“任务工作台 → 计算模拟”页面迁移作为基础。不是源项目“项目流程 V3”，也不是普通非计算任务的“工作流画布”。当前源码在 `apps/web`；`dist`、`versions/v1`、`public/archives/workflow-v2` 均不作为当前迁移源。

原型设计优先级：用户最新业务范围 > 源项目当前计算模拟页面及有效样式 > 本目录布局说明 > 早期截图。源码可访问时必须先读取再迁移，不能只靠本文件中的尺寸近似重画；不可访问时明确缺少源文件，不能宣称已完成迁移。

业务适配仅替换菜单、上下文、计算对象和结果方式。源项目的项目概览、项目流程、阶段任务、项目资产、回收站及阶段完成逻辑不进入本项目。Copilot 作为源计算模拟页面的界面组成迁入，使用本地演示交互，不承诺真实 AI 服务。

## 整体菜单

这里的“整体”指材料研发系统的导航，不引入项目管理对象。现有系统完整菜单尚未提供，以下为围绕已知分子库、微观模拟和本次新增能力的导航建议；已有系统的其他菜单由原系统保留。

```text
材料研发平台（名称占位，可替换）
├─ 分子库                     已有能力入口
├─ 微观模拟                   已有能力入口
├─ 计算工作流                 默认入口
└─ 作业与结果                 运行记录及结果入口

计算工作流 → 工作流编排工作台  独立路由，仍选中“计算工作流”
工作台 → 指定作业与结果        携带工作流、执行记录和节点上下文
```

分子库、微观模拟只作为既有入口，不在这轮原型中重建。无需新增首页仪表盘、材料卡、项目、团队、审批、方案比较、资源管理或设置页面。用户账户沿用系统已有入口。

四个入口均为一级菜单，不添加“跨尺度模拟”父级。工作流编排工作台不出现在菜单中：用户点击列表中的工作流名称或“编辑”后进入独立页面；新建工作流后同样进入该页面。

## 路由和导航行为

| 页面 | 建议路由 | 左侧菜单选中项 | 页面内导航 |
| --- | --- | --- | --- |
| 工作流列表 | /multiscale/workflows | 计算工作流 | 本轮原型默认入口 |
| 工作流编排工作台 | /multiscale/workflows/:workflowId/edit | 计算工作流 | 面包屑：计算工作流 / 工作流名称 / 编辑；无独立菜单项 |
| 作业与结果 | /multiscale/runs | 作业与结果 | 从工作台进入时定位到指定执行记录 |

保留 `/multiscale` 作为内部路由前缀，不代表存在同名菜单。作业选择可使用查询参数 `runId`，节点选择可使用 `nodeId`，按原型工具支持情况实现。返回工作台时恢复工作流和选中节点。三个页面应使用同一份模拟数据，避免同一作业在不同页面呈现不同状态。

## 公共页面框架

- 桌面参考尺寸 1440 × 900，补充 1920 × 1080 和 1280 像素宽度下的布局。
- 顶部栏、侧栏和页面间距直接复用源项目有效样式。源基础侧栏为 184 像素，顶部栏为 58 像素；后续样式覆盖和响应式规则优先，不再按此前 208/56 像素另建框架。
- 左侧四个一级菜单沿用源项目图标、选中背景和底部账户布局，移除项目专用导航。
- 工作台采用源计算模拟页的“左 Copilot + 右依赖图与配置”结构，响应式侧栏收缩和画布横向滚动沿用源规则。
- 使用源项目的内容边距、吸顶操作栏和滚动分区，保持 Copilot 输入区可见。
- 不要在工作台外再创建“流程总览”页面。工作台画布本身承担依赖关系展示。

## 状态与数据约定

- 工作流定义状态：草稿、可运行、需更新。节点数只是结构信息，不作为任务进度。
- 执行状态：排队中、运行中、成功、失败、已取消。没有执行记录显示“尚未运行”。
- 节点状态：待配置、待校验、校验失败、等待上游、排队中、运行中、成功、失败、已取消、已过期。
- 工作流当前定义与历史执行快照分开。编辑不会覆盖历史结果；更新上游后，下游标记已过期。
- 作业结果以“仿真结果报告文件 + 本次仿真结论”呈现。结论是已经整理好的文本，直接阅读和复制；不增加对话生成或 AI 分析流程。
- 报告可以在线预览和下载；原型以 PDF 演示，实际格式待接口确认。主要指标写在报告及结论中，不额外建设复杂结果分析区。
- 本轮结果页不提供三维场图、切面、选点、轨迹播放器或三维查看工具。工作台中的建模预览仍用于几何配置。
- 具体求解器结果文件格式尚未确定。所有数值、报告文件名和结论均标注为原型演示数据，不暗示真实求解或已完成格式联调。
- 求解状态与报告状态独立：求解成功、报告生成中时不得显示最终结论；报告失败不把已成功求解改成失败。
- 根据本轮迁移要求，工作台保留源计算模拟页左侧研究 Copilot、对话和输入区，演示上下文定位；不迁入源项目的负责人、待办协作和阶段任务完成按钮。节点文件引用按已有输入与报告适配，不扩展通用资产管理。Copilot 消息不能替代算法校验或自行生成缺失物性。

## 原型生成与验收

生成可交互原型，模拟搜索、筛选、新建、节点选中、连线映射、校验、运行和结果切换。点击后的反馈应具体。已有功能入口可显示“打开现有功能”占位反馈，不必实现新页面。

以“工作流列表 → 新建或继续编辑 → 工作台配置与校验 → 执行 → 作业与结果 → 返回工作台”为主要演示路径。模拟求解要有演示标识；失败、等待和已过期不能渲染成成功。不得自动编造物性、边界、缺失结果或收敛结论。

## 2. 产品目标

围绕一个模拟任务，连接材料分子数据、微观建模、物性获取、宏观建模、计算调度和结果报告，形成可编辑、可检验、可追溯的跨尺度模拟工作流。

核心目标：

1. 通过应用类型初始化适合当前场景的宏观模型，降低从零配置的成本。
2. 将模型中的结构与材料库中的材料数据分开管理，明确几何、材料引用和微观计算之间的关系。
3. 以宏观建模为主交互区，以工作流表达依赖关系，二者选中状态和数据保持联动。
4. 将微观建模与微观物性计算拆成独立节点，支持一个模型对应多项物性计算。
5. 执行前检验模型和工作流；执行时固化输入，后续编辑不改变历史记录。

### 2.1 本期范围

本期覆盖跨尺度模拟任务列表、新建任务、宏观建模工作台、结构与材料配置、微观建模弹窗、物性获取参数配置、工作流画布、建模检验及演示执行。

作业与结果以报告和文本结论为本期呈现方向。完整作业管理、真实算法调用、真实 CAD/网格计算、场结果后处理属于后续接入和建设内容。

### 2.2 当前不建设的内容

- 不重建系统已有的首页、独立分子库和微观模拟业务。
- 当前工作台不提供 Copilot 对话栏及相关画布入口。
- 不在当前版中建设项目管理、成员邀请、审批或模板管理。
- 本期结果页不建设三维场云图、切面选点和轨迹播放器。
- 不将当前几何示意、分子示意或演示报告作为真实计算依据。

## 3. 业务概念与关系

| 概念 | 定义与关系 |
| --- | --- |
| 模拟任务 | 用户创建和管理的业务对象，包含名称、应用类型、建模配置、工作流及执行记录 |
| 工作流 | 模拟任务内部的节点和依赖图，不要求是一条单线，可包含分支和汇合 |
| 应用类型 | TIM材料、挤出模拟、简单圆管示例、空白工作流，决定初始建模场景和交互 |
| 几何体 | 模型中的可视化几何对象，具有类型、尺寸、位置和稳定标识 |
| 模型结构 | 当前模型中的基底、材料1、材料2等对象，持有名称、形貌、显示颜色、分配区域和材料引用 |
| 材料库数据 | 独立的材料及分子数据，多个模型结构可以引用同一条记录 |
| 微观模型 | 对应结构的分子建模输入，可用于多个物性计算；在原型中为分子示意草稿 |
| 物性计算 | 基于微观模型和获取方式生成物性的独立计算环节 |
| 执行记录 | 某一次运行的输入快照、状态、日志和结果，不随当前草稿修改 |

### 3.1 结构与材料的分离原则

“球状”“片状”属于模型结构的形貌选项，不是两种材料库分类。结构名称和材料名称分别保存，例如“材料1”可引用“氧化铝”，形貌可设置为球状。

修改结构名称、形貌或显示颜色，不修改材料库。微观建模弹窗的修改应用到当前任务对应的微观节点，不直接覆盖材料库分子数据。

### 3.2 特殊规则：挤出模拟

四个管段属于几何分段，整体共用一种材料。不为每个管段建立独立材料设置或独立微观计算分支。整体材料对应一组微观建模与材料计算节点，其中材料计算节点只有一个默认实例。

- 控件具备可辨认的悬浮、选中、禁用和键盘焦点状态；图标工具提供名称提示。
- 桌面优先，窄屏允许工具分组换行、表格横向滚动，不相互覆盖。

## 5. 模拟任务列表与新建

### 5.1 列表

已有交互：名称搜索、计算类型筛选、定义状态筛选、最近执行筛选、清空筛选、更新时间排序及任务操作。

| 字段 | 要求 |
| --- | --- |
| 工作流名称 | 可进入工作台；下一行显示用途说明 |
| 计算类型 | 区分 TIM 导热、挤出模拟、流动、通用等类型 |
| 节点数 | 显示当前节点总数，包含开始和结束节点 |
| 定义状态 | 草稿、可运行、需更新，表示当前定义的就绪情况 |
| 最近执行 | 显示最近一次运行状态和时间，与定义状态独立 |
| 更新时间 | 展示本地时间，支持排序 |
| 操作 | 编辑、查看作业，以及更多菜单中的复制、重命名、删除 |

交互规则：

1. 无任务时提供创建入口；筛选无匹配时提供清空筛选。
2. 复制任务保留当前节点与配置，清空历史运行，使用新名称和独立任务标识。
3. 重命名不能为空；新建名称当前上限为40个字符。
4. 删除需二次确认。产品要求定义删除与历史作业留存分离；当前原型删除后独立查询历史作业的入口仍需完善。
5. 运行中编辑仅影响后续定义，不修改已提交的执行快照。
6. 当前分页控件为展示占位；真实分页、加载和失败重试属于待建设能力。

### 5.2 新建任务

弹窗标题为“新建模拟任务”，名称字段为“任务名称”，选项区域为“应用类型”。底部提供“取消”和“创建并编辑”。

| 排序 | 应用类型 | 初始宏观模型 | 初始工作流 |
| --- | --- | --- | --- |
| 1 | TIM材料 | 方块基底及一种球状填料 | 基底与填料各有微观建模、物性计算分支，默认9个节点 |
| 2 | 挤出模拟 | 圆柱、圆锥过渡段、圆柱、圆锥过渡段，连续连接 | 整体共用一种材料，默认7个节点 |
| 3 | 简单圆管示例 | 一个圆柱体，代表圆管模型 | 一组材料分支，默认7个节点 |
| 4 | 空白工作流 | 无初始几何和材料结构，但保留完整建模视区和工具 | 保留7类基础节点及阶段连接，参数待配置 |

当前原型默认选择空白工作流。节点数为默认初始化说明，用户增加计算分支或结构后按实际更新。所有新任务执行前均需检验。

## 6. 模拟工作台

### 6.1 布局

页面从上到下为：任务名称及保存状态、检验与运行操作、运行反馈、宏观建模区、计算依赖图。

宏观建模是主交互区，始终保留在工作流上方。工作流选择微观、计算、调度或结果节点时，不将上方视区替换成其他类型的预览。对应参数使用弹窗配置。

建模区包括：

- 简洁标题和操作栏。
- 常用建模快捷入口。
- 左侧主要模型视区：几何快捷工具、视图工具、模型结构标签和模型。
- 右侧应用类型、模型名称及当前应用尺寸/参数。
- 底部紧凑的建模检验状态栏，出现问题时展开问题清单。

模型视区应利用所在行的高度，不保留无意义的底部空白。

### 6.2 界面精简规则

当前版不显示以下内容：

- Copilot 对话栏、收起入口及画布对话引用操作。
- 页头“需更新”状态徽章；定义状态仍可在列表管理。
- “宏观模型 · 定义版本 · 原型演示”说明行。
- “模型与配置 / 变更记录”标签行。
- “方块基体 / 内部填料 · 材料选择演示”说明行。
- 独立的几何尺寸、网格和工况摘要行。
- “输入映射与来源”表格区域。
- “网格设置”“物理场与边界”“研究设置”三个快捷按钮。
- “显示网格”按钮。
- 工作流标题下的完整阶段链路说明行。

上述精简不意味着删除历史输入、依赖关系、版本和执行快照。

## 7. 宏观建模能力

### 7.1 常用工具

| 工具组 | 功能与要求 |
| --- | --- |
| 模型设置 | 几何设置、材料管理、清除选择、适应模型、标准视图；TIM保留透明基体 |
| 基础几何 | 长方体、球体、圆柱体、圆锥体；更多几何中有椭球体、圆环体 |
| 视图操作 | 放大、缩小、适应全部、选择材料、旋转、平移、线框显示 |
| 显示控制 | 隐藏选中材料、显示全部材料、坐标轴显隐 |
| 导出 | 模型截图预览与 PNG 保存 |

旋转工具使用手形图标。选择、旋转和平移有明确模式反馈。视图操作不修改材料参数或计算输入。

### 7.2 几何创建、选择与删除

1. 点击几何工具，打开名称、尺寸和位置配置弹窗。
2. 确认后将几何体加入当前模型，更新预览。
3. 几何体可在模型中或对应对象入口选中，并以轮廓/颜色反馈。
4. 选中后提供“编辑几何体”“删除几何体”快捷操作；支持在几何选择上下文使用删除键。
5. 删除对应对象及其关联配置，保留其他对象；相关模型输入改变后重新检验。
6. 几何删除与结构删除是不同操作，不将二者混用。
7. 当前仅为几何实体示意，不具备真实 CAD 布尔、拓扑修复或网格生成能力。

### 7.3 TIM材料场景

- 初始化方块基底和一种球状填料。这里“一种材料”的演示口径指一种填料，基底仍然存在。
- 提供添加材料/结构入口，加入第二种片状填料；添加后可进入材料管理继续调整。
- 球状以颗粒表示，片状以有厚度的薄片表示；颜色跟随结构设置。
- 两种填料并存时，加上基底共三个结构，默认形成三组微观建模与物性计算分支，共11个节点。
- 新增、重选、删除结构后，预览、结构标签和关联工作流分支同步更新。
- 快捷菜单允许删除额外填料，恢复“基底＋一种填料”的演示状态；不在该菜单删除基底或最后一种填料。
- 尺寸、颗粒分布、随机种子和间隙等为参数化演示；真实有效填充率和几何质量由后续算法确定。

### 7.4 挤出模拟场景

初始模型按流动方向依次为四段，圆锥段采用有入口和出口半径的截锥过渡结构。

| 几何段 | 类型 | 当前演示默认尺寸，单位mm | 可编辑参数 |
| --- | --- | --- | --- |
| 1 | 圆柱 | 长120，半径20 | 长度、半径 |
| 2 | 圆锥过渡段 | 长60，入口半径20，出口半径10 | 长度、入口半径、出口半径 |
| 3 | 圆柱 | 长60，半径10 | 长度、半径 |
| 4 | 圆锥过渡段 | 长80，入口半径10，出口半径5 | 长度、入口半径、出口半径 |

规则：

1. 四段按顺序连续连接，编辑长度后自动重排位置，编辑接口半径时联动相邻接口尺寸。
2. 四段只提供几何尺寸编辑，不各自配置材料，不生成四组微观节点。
3. 整体材料统一选择和配置，对应一个默认材料计算节点。
4. 视区不标注“第1段”“第2段”等名称；右侧尺寸入口可以保留名称便于编辑。
5. 拖动只改变观察角度，保持固定比例，不随投影范围自动放大、缩小或重新居中。
6. 滚轮和缩放按钮仍可主动缩放，“适应模型”可重新适配。
7. 显示与模型使用同一三维投影的 XYZ 坐标网格、单位和数值标尺；旋转时位置跟随，文字保持可读。
8. X方向增加刻度密度。当前采用约8个目标分段，按模型范围生成适宜的实际间隔，避免刻度重叠。

以上尺寸是可修改的演示初始化值，不是算法边界。

### 7.5 简单圆管与空白场景

简单圆管初始化一个圆柱体，默认长度100mm、半径5mm，可编辑长度和半径；预览与输入联动。不展示 TIM 基底或颗粒。

空白工作流不初始化几何或材料，保留几何工具、材料管理、视图工具、右侧配置和基础工作流节点。空状态说明如何开始建模，不能用一块空白替代整个工作区。创建几何或应用可视化结构配置后，模型应立即出现。未配置完整时应由建模检验说明缺失项。

## 8. 结构与材料管理

### 8.1 常规材料管理弹窗

弹窗以“模型结构”为主组织内容：左侧结构清单和添加结构，右侧为选中结构的设置。

| 字段/区域 | 要求 |
| --- | --- |
| 结构名称 | 基底、材料1、材料2等，可编辑，与材料库名称区分 |
| 显示颜色 | 控制模型和标签颜色，不改写材料库 |
| 结构形貌 | 填料可选球状或片状；基底及管段按所属场景限制 |
| 对应材料 | 选择材料库记录，保留稳定引用标识 |
| 已引用材料数据 | 只读展示材料名、引用、密度等信息；热导率显示“未知” |
| 关键物性参数 | 常驻展开区域，提供属性及获取方式配置 |
| 操作 | 添加/删除结构、取消、应用结构与材料 |

多个结构允许引用同一条材料库数据，但名称、形貌和物性配置分别保存。未选择材料的新增结构不能应用。取消关闭弹窗不修改当前模型，应用后同步保存并更新工作流。

挤出模式使用整体材料设置：只显示一项整体材料，不提供管段级添加材料、形貌分配或四段独立材料设置。

### 8.2 选择和节点联动

- 点击结构名称按钮选中时，快捷菜单紧贴该按钮。
- 在可视化模型中选中材料时，快捷菜单出现在选择位置附近。
- 选择结构时，同步选中其微观建模节点。
- 选择微观建模或物性计算节点时，在宏观视区选中对应结构。
- 结构菜单提供微观建模、材料属性、清除选择，以及满足条件时的删除结构。
- 点击微观建模才打开分子建模弹窗，不通过选中操作替换上方建模区。
- 挤出模式选择单个管段只定位几何，不建立管段独立的微观材料分支。

### 8.3 关键物性与获取方式

属性选项为 `tg`、`tc`、`CTE`；获取方式为 MD、DFT、手动输入。每个结构按属性分别保存配置，切换属性或获取方式后保留各自已填内容。

当前物性区域名称为“关键物性参数”，不再使用“选择材料库数据”的折叠标题。不得将MD/DFT配置完成等同于物性结果已经获得。

#### MD参数

| 分组 | 字段 | 当前默认值与交互 |
| --- | --- | --- |
| 基本设置 | 计算链数 | 5链；数字输入及减/加按钮，最小1 |
| 属性 | tg、tc、CTE | 下拉选择 |
| 高级设置 | 开关 | 默认开启，控制温度与数据点表单的显示 |
| 温度，K | 开始、结束、平衡 | 100、600、100，数字输入及减/加按钮 |
| 数据点 | 帧、间隔 | 200、1000，数字输入及减/加按钮，最小1 |

温度三个字段沿用当前确认表单。“平衡”的算法含义、间隔的物理单位、适用温度范围及关联约束需在真实任务接入时确认。

#### DFT参数

| 字段 | 当前选项/默认值 |
| --- | --- |
| 计算类型 | 默认紫外可见光谱；另有结构优化、单点能、振动频率 |
| 泛函 | 默认B3LYP；另有PBE、PBE0 |
| 基组 | 默认6-31g；另有6-31g(d)、def2-SVP |
| 方法 | 默认RKS；另有UKS |
| 激发态数量 | 默认10，非负整数，减/加及输入 |
| 分子电荷 | 默认0，允许负数，减/加及输入 |
| 未成对电子数 | 默认0，非负整数，减/加及输入 |

以上是原型表单选项；计算类型与方法的有效组合、电子数及电荷一致性由真实计算契约确定。

手动输入方式只提供参数值输入框。属性单位、数值范围和手动结果来源记录为待确认项。

## 9. 微观建模弹窗

已有交互采用左右双栏：左侧二维分子式编辑，右侧三维球棍模型预览。

二维侧提供基础工具：选择/移动、元素选择、添加原子、删除、单/双/三键、环结构示例、清空、撤销/重做、氢原子显示和分子名称编辑。无需在当前阶段实现专业化学编辑器的全部能力。

三维侧随草稿更新，支持旋转、缩放、重置视角和标签显示。示例分子不代表当前材料的真实结构。

保存规则：

1. 弹窗内操作先保存为草稿。
2. 取消不修改当前节点。
3. 应用后仅更新当前结构对应的微观建模输入，使受影响的下游节点待更新。
4. 材料库记录和历史执行快照保持不变。
5. 当前只进行基础结构数据检查，不提供完整SMILES解析、化学价校验、能量优化或真实分子计算。

## 10. 工作流编排

### 10.1 节点与配置入口

| 类型 | 作用 | 配置方式 |
| --- | --- | --- |
| 开始 | 唯一工作流入口 | 不配置科学计算参数 |
| 微观建模 | 提供分子结构输入 | 打开微观建模弹窗 |
| 微观物性计算 | 基于微观模型获取物性，一个模型可连多个计算节点 | 参数弹窗；当前仍有热导率、密度、黏度、弹性模量及任务引用等演示字段 |
| 宏观建模 | 汇总材料输入和物理模型 | 使用页面上方常驻建模区，不提供“打开配置”弹窗 |
| 计算调度 | 接收宏观模型并执行计算 | 弹窗设置依赖策略、资源、核数、重试次数，当前仅本地演示 |
| 结果呈现 | 输出报告与文本结论 | 参数弹窗及作业结果入口 |
| 结束 | 唯一工作流终点 | 不配置科学计算参数 |

材料管理中的 `tg/tc/CTE` 配置与物性计算节点中的旧演示字段目前并存；应用材料配置会同步相关计算节点的材料引用及物性配置。正式开发需要统一字段模型和配置入口，不能将两套下拉选项视为已经完成一致化。

### 10.2 连接与检验规则

阶段顺序为：开始 → 微观建模 → 微观物性计算 → 宏观建模 → 计算调度 → 结果呈现 → 结束。

1. 仅允许相邻阶段正向连接，不允许反向、同阶段、跨阶段和自连接。
2. 必须有且仅有一个开始节点和一个结束节点。
3. 工作流必须有向无环，所有节点都处在从开始到结束的完整路径上。
4. 允许一对多和多对一，支持多个结构分支及同一微观模型的多个物性计算。
5. 缺失阶段、断开分支、无输入/输出或无法到达终点的节点阻止运行。
6. 不用某个TIM算例的字段类型限制全平台阶段连线；具体单位与物理字段映射在模型及接口层检验。
7. 错误提示说明原因和允许的目标类型，避免仅显示“输出类型与目标不兼容”。

### 10.3 无限画布交互

已有交互包括：平移、缩放、节点拖动、吸附、框选多选、四侧端口连接、连线操作、节点创建/删除、缩略图、当前节点定位、自动布局、撤销/重做。

- 工具条提供缩小、缩放比例、放大、适应画布、当前节点和自动布局。
- 自动布局改变位置与连线路由，不改变业务依赖。
- 节点卡片只展示简洁类型、名称、状态和输出摘要；隐藏内部长编号。
- 类型与状态分开排布，避免文字叠加。内部过期状态在卡片中显示“待更新”。
- 不显示节点悬浮属性弹窗。
- 选择菜单按节点类型提供操作；宏观建模节点不显示“打开配置”。
- 节点和连线删除支持确认及撤销，历史执行记录不随当前图编辑删除。

### 10.4 全屏与恢复

工作流提供“全屏 / 恢复”。全屏时保留主菜单，主菜单右侧可用区域铺满工作流；当前已移除AI对话栏，因此不预留其空间。

全屏下仍可编辑节点、连线和打开参数弹窗。支持Esc恢复。进入全屏和恢复后，都在布局尺寸稳定后自动适应当前画布内容，避免内容偏移或被截断。

## 11. 建模检验、状态与执行

### 11.1 建模检验

统一按钮名称为“建模检验”，页头可触发，建模区底部提供常驻紧凑状态栏，不使用折叠容器。

未检验显示“尚未检验当前修改”；通过显示“检验通过”；失败显示问题数和可定位的问题列表。通过状态不占用多行高度。

检验范围包括：工作流完整性与DAG规则、节点必填输入、基础分子数据、几何尺寸、材料分配及当前案例演示参数。真实几何拓扑、网格质量和算法适用范围检验待服务接入。

### 11.2 状态与变更传播

定义状态、节点状态、运行状态和报告状态分别管理。

| 状态对象 | 规则 |
| --- | --- |
| 任务定义 | 草稿、可运行、需更新；修改后重新检验 |
| 节点 | 待校验、待更新、运行中、成功、失败、已取消等；待更新表示原结果不再匹配当前输入 |
| 执行 | 当前原型主要演示运行中、成功、已取消；完整队列及失败恢复待建设 |
| 报告 | 等待上游、生成中、已生成、失败；与执行成功/失败独立 |

“待更新/已过期”表示历史输出对应旧输入，不是材料失效，也不是数据自动删除。修改上游输入应影响相关下游，保留原执行快照和报告。

### 11.3 执行

1. 运行前必须检验当前版本，存在问题则阻止执行。
2. 当前实现中，若运行时发现当前修改尚未检验，先执行检验，通过后需再次点击运行。
3. 每次运行生成独立执行标识、输入快照和日志，按依赖顺序演示节点完成。
4. 提供整体运行和符合上游条件的节点运行入口。
5. 运行中显示进度、取消执行和查看本次作业。
6. 取消保留当前配置与本次快照，不产生成功报告。
7. 当前仅模拟进度和结果状态，不调用真实MD、DFT、FVM或计算资源。

## 12. 作业与结果

### 12.1 当前实现

当前提供指定任务的执行概要、执行与报告状态、成功后的演示结论、日志、只读输入快照和返回工作台入口。结果呈现节点提供演示报告预览、PDF下载及复制结论。

TIM数值来自固定演示样本，不由用户修改的参数推算。简单圆管与通用流程不生成未经真实算法计算的物理指标；挤出目前没有专属求解结果模板。

从主菜单直接进入时，当前尚未建设完整的跨任务运行记录列表。因此，不能将现有概要页作为完整“作业与结果”模块验收。

### 12.2 待建设的完整需求

- 可搜索和筛选的执行记录，按任务、执行ID、类型和状态定位。
- 结果报告、日志与诊断、输入快照三个区域或页签。
- 已总结的文本结论及复制；报告文件状态、预览、下载及生成失败重试。
- 求解成功而报告失败时，只重试报告生成，不重新执行求解。
- 未完成、失败、取消时不借用其他执行的成功结论。
- 历史报告明确提示所依据的历史输入，切换执行时报告和下载同步切换。
- 原始求解文件按实际格式保存，不能用演示PDF替代原始结果。
- 时间使用Asia/Shanghai；真实创建、修改和执行时间由统一时间来源生成，替换当前部分固定演示时间。

## 13. 保存、版本与数据要求

### 13.1 当前原型

- 当前任务草稿、节点配置及执行信息按任务标识在浏览器本机保存。
- 展示保存中、已保存在本机、失败及重试反馈。
- 结构、几何、节点和材料库引用具有独立标识，不以显示名称作为关联键。
- 修改配置使当前检验失效；执行快照只读。
- 旧版节点拆分、终端补齐和挤出材料合并保留迁移备份，不修改历史执行快照。
- V1归档位于“演示说明 → 工作流编辑 V1”，当前版与V1数据、代码和样式隔离。

### 13.2 正式系统的数据对象

| 对象 | 必要信息 |
| --- | --- |
| 模拟任务 | 标识、名称、应用类型、定义版本、状态、创建/修改时间 |
| 几何与结构 | 标识、几何类型、尺寸、单位、位置、区域、形貌和显示属性 |
| 材料引用 | 材料库标识、版本、分子输入引用、只读数据快照 |
| 物性配置 | 属性、单位、获取方式、MD/DFT/手动参数、结果引用及适用条件 |
| 工作流节点与依赖 | 类型、参数、端口、来源、版本、连接和画布位置 |
| 执行 | 输入快照、算法版本、状态、日志、时间和错误信息 |
| 结果与文件 | 所属执行、结论、报告状态、原始文件、格式和下载索引 |

正式系统应具备服务端持久化、权限控制、真实任务状态恢复、文件完整性与审计；当前本机保存不作为这些能力的替代。

## 16. 运行详情与任务管理补充（2026-11-09）

本节更新第10—12章的执行交互，详细页面设计见[工作流运行详情页设计](./工作流运行详情页设计.md)。

- 工作台提供运行全部、运行所选及上游依赖、暂停、继续运行。部分执行不默认提交所有下游。
- 完成节点锁定参数和结果，仅允许查看；未完成节点可修改参数。修改执行中的参数会重新排队，并保留每次实际输入记录。
- 运行期间图结构固定，新增/删除节点及连线暂不可用；画布观察和布局操作保留。需要改变结构时复制任务。
- 工作流直接展示完成、运行、等待、阻塞等状态，下方新增计算任务列表，支持状态筛选、节点定位、配置、日志和重试。
- 某分支阻塞不阻止独立分支继续推进；重试或继续运行跳过已完成节点。
- 刷新后的本地演示执行保留为可继续状态；真实后台持续计算仍待服务接入。
- 提供明确标记的全部运行、部分运行、节点阻塞、全部完成演示场景；切换场景生成独立执行记录并保留原历史。
- 新增验收：部分执行范围正确；完成节点无法被材料/几何弹窗间接修改；重试不重算完成任务；任务列表、图和概况状态一致；提交快照及实际执行输入可追溯。

# 跨尺度模拟系统需求简版

## 1. 产品目标与范围

### 1.1 产品目标

系统通过 Web 建设计算工作流，连接系统已有的分子库和微观模拟能力，以及待接入的 Forge FVM 宏观工程仿真。

目标：

1. 增加计算工作流能力，编排已有微观模拟节点、数据转换节点和宏观仿真节点。
2. 能够通过受控模板配置 TIM 或流动算例，完成校验、网格、材料及边界设置、求解和结果查看。
3. 系统能够记录节点间传递的数据、单位、来源、适用条件和版本，避免将简单连线误认为已完成物理映射。
4. 对超出 Forge FVM V1 算法边界应在提交前阻止或明确提示。

### 1.2 V1 建设范围

1. 建设计算工作流的创建、编辑、执行和查看能力。
2. 建设工作流节点、依赖、数据映射、状态和版本记录能力。
3. 在工作流中引用和编排系统已有的分子库与微观模拟功能。
4. 建设 TIM 参数化建模、校验、设置、提交和结果展示能力。
5. 建设简单流道参数化建模、校验、设置、提交和结果展示能力。
6. （简化）建设计算作业队列、日志、失败诊断、取消和重试能力。
7. 展示标量结果和场结果，并支持追溯工作流输入、节点输出和算法版本。

## 2. 核心业务流程

### 2.1 计算工作流

1. 用户创建计算工作流。
2. 用户添加已有微观模拟、性质提取或拟合、TIM、流动等节点。
3. 微观模拟节点从系统已有分子库选择输入，并复用已有微观计算能力。
4. 用户为节点配置输入，建立明确的数据映射关系。
5. 系统执行所选算法要求的相关检验，包括输入完整性、参数范围、几何有效性、区域与边界绑定以及算法适用范围检验。
6. 用户执行工作流。系统按依赖顺序调度节点，并记录输入快照、算法版本、任务状态和日志。
7. 计算完成后，系统保存节点输出、来源和适用条件。
8. 上游输入或输出发生变化时，系统将受影响的下游节点标记为“已过期”，由用户决定是否重新计算。

### 2.2 宏观仿真流程

1. 创建或选择参数化几何。
2. 执行几何校验并修正问题。
3. 生成或导入网格。
4. 为区域指定材料、界面和边界条件。
5. 执行提交前校验。
6. 生成算法输入并提交 Forge FVM 作业。
7. 查看作业状态、日志和错误信息。
8. 查看标量结果与场结果。

## 3. 功能需求

优先级定义：P0 为端到端首版必需，P1 为建议纳入但可在首版范围评审中调整，P2 为后续能力。

Forge FVM V1 的适用范围、输入输出及不支持项以 [Forge FVM V1 算法边界](./Forge--FVM%20V1算法边界.docx) 为准，本需求不重复定义算法边界。

### 3.1 计算工作流

| 序号 | 需求名称 | 优先级 | 需求 |
| ---: | --- | --- | --- |
| 1 | 工作流创建 | P0 | 用户可以创建、打开、重命名和复制计算工作流。 |
| 2 | 节点编辑 | P0 | 用户可以新增、连接、配置和删除流程节点。 |
| 3 | 节点信息 | P0 | 每个节点应显示输入、输出、状态、版本、运行记录和诊断信息。 |
| 4 | 数据映射 | P0 | 节点连线必须配置实际数据映射，不能只保存视觉连接。 |
| 5 | 接口校验 | P0 | 系统应校验节点输入输出的数据类型、单位和适用范围。 |
| 6 | 执行前校验 | P0 | 系统应阻止缺少必填输入或存在无效映射的节点执行。 |
| 7 | 依赖调度 | P0 | 系统应按节点依赖顺序执行工作流，并支持从指定节点开始运行。 |
| 8 | 执行快照 | P0 | 每次执行应固化工作流版本、节点输入、算法版本和提交时间，不因后续编辑而改变历史结果。 |
| 9 | 过期标记 | P0 | 上游节点输入或输出变化后，系统应将受影响的下游节点标记为已过期。 |

### 3.2 微观模拟计算

本节能力由系统现有功能提供。V1 只建设其与计算工作流的集成，不重复开发分子库或微观求解功能。

| 序号 | 需求名称 | 优先级 | 需求 |
| ---: | --- | --- | --- |
| 10 | 微观输入引用 | P0 | 工作流应能引用系统已有的分子结构或微观模拟输入。 |
| 11 | 微观任务接入 | P0 | 工作流应能发起或引用已有微观模拟任务，并读取任务状态。 |
| 12 | 微观结果映射 | P0 | 工作流应能获取微观模拟的结构化输出，并映射到下游节点输入。 |
| 13 | 既有能力边界 | P0 | 微观模拟任务的输入、状态、输出和错误信息仍由现有功能负责，工作流仅保存引用和必要快照。 |
| 14 | 结果变更联动 | P0 | 当引用的微观模拟结果发生变化时，依赖该结果的下游节点应标记为已过期。 |

### 3.3 几何、区域和网格

| 序号 | 需求名称 | 优先级 | 需求 |
| ---: | --- | --- | --- |
| 15 | 几何模板 | P0 | 系统应提供 TIM 长方体复合材料模板和简单圆管流道模板。 |
| 16 | 参数化预览 | P0 | 模板参数修改后应更新三维预览，并保留可用于材料和边界绑定的稳定区域标识。 |
| 17 | 几何校验 | P0 | 几何校验至少覆盖布尔结果、共享节点、区域超限、连接关系和相切情况。 |
| 18 | 问题定位 | P0 | 校验问题应定位到对象或区域，并给出可理解的原因和处理建议。 |
| 19 | 网格前置条件 | P0 | 只有几何校验通过后才允许进入网格和求解步骤。 |
| 20 | 网格记录 | P0 | 网格生成应保存工具版本、参数、质量统计和网格文件。具体格式待算法契约确认。 |
| 21 | 区域与边界选择 | P1 | 用户可以在三维视图中选择对象、区域和边界面，并在设置面板中完成绑定。 |
| 22 | CAD 导入 | P2 | 系统支持 CAD 导入及有限的尺寸或特征编辑。 |

### 3.4 Forge FVM 作业接入

| 序号 | 需求名称 | 优先级 | 需求 |
| ---: | --- | --- | --- |
| 23 | 输入适配 | P0 | 系统应通过独立适配层将结构化算例转换为 Forge FVM 输入文件或接口请求。 |
| 24 | 提交前校验 | P0 | 提交前应执行字段完整性、单位、算法边界、区域绑定和文件完整性校验。 |
| 25 | 作业状态 | P0 | 作业状态至少包括草稿、待校验、校验失败、排队、运行、成功、失败、取消。 |
| 26 | 日志与运行记录 | P0 | 系统应保存标准输出、错误输出、错误码、开始时间、结束时间和运行环境标识。 |
| 27 | 作业取消与重试 | P0 | 用户可以取消未完成作业，并在修正输入后重新提交。 |
| 28 | 版本绑定 | P0 | 同一作业只能引用一个明确的求解器版本和输入快照。 |
| 29 | 失败恢复 | P1 | 系统支持从失败步骤恢复，避免重复执行已成功且输入未变化的步骤。 |

### 3.5 结果展示

| 序号 | 需求名称 | 优先级 | 需求 |
| ---: | --- | --- | --- |
| 30 | 标量结果展示 | P0 | 系统应展示算法定义的必需标量结果，并显示单位、方向和工况。 |
| 31 | 原始结果保存 | P0 | 系统应保存原始结果文件，不以网页展示数据替代原始结果。 |
| 32 | 结果解析 | P0 | 结果适配器应读取 Forge FVM 的实际输出格式，并提取标量、网格、场值、单位和坐标系。 |
| 33 | 场结果可视化 | P0 | 对场结果，系统应支持三维云图、切面和图例。 |
| 34 | 可视化格式转换 | P0 | 当求解器原始格式不适合网页读取时，系统应生成标准化可视化文件，同时保留原始文件。 |
| 35 | 切面选点 | P1 | 用户可以旋转三维切面，并在切面上选点读取坐标和场值。 |
| 36 | 结果来源标识 | P0 | 系统应明确区分求解器结果、导入结果和未来可能提供的 AI 预测结果。 |

## 6. 非功能需求基线

下列为 V1 建议基线，具体指标需在获得真实算例后确定。

| 编号 | 类别 | 需求 |
| --- | --- | --- |
| NFR-001 | 可追溯性 | 任一结果均可追溯到工作流节点、输入快照、上游微观结果、网格和求解器版本。 |
| NFR-002 | 可重复性 | 对相同输入和相同算法版本，系统应保留足够信息用于重复运行。随机颗粒生成必须保存随机种子或实际几何。 |
| NFR-003 | 单位一致性 | 所有物理量应使用显式单位；接口层应进行单位转换或拒绝不兼容输入。 |
| NFR-004 | 数据完整性 | 生成和上传文件应记录校验和；任务产物不得静默覆盖。 |
| NFR-005 | 安全 | 复用系统现有身份认证和访问控制；关键操作和算法版本变更应记录审计日志。 |
| NFR-006 | 可靠性 | 页面刷新或网络短时中断不得中止服务端计算；用户可恢复查看作业状态。 |
| NFR-007 | 可诊断性 | 校验和求解失败应返回可定位的阶段、对象、错误码和原始日志。 |
| NFR-008 | 扩展性 | 几何、网格、求解器和结果解析应通过模块化适配器接入，避免把具体文件格式固化在页面逻辑中。 |
| NFR-009 | 性能 | 页面、模型规模、网格规模、上传下载和并发指标在基准算例确认后制定，不在本草案中预设数字。 |

## 7. V1 验收场景

### 7.1 计算工作流

1. 用户创建工作流，并添加已有微观模拟、数据转换和 TIM 或流动节点。
2. 微观模拟节点可以引用系统已有的分子结构，发起或关联已有任务，并同步任务状态。
3. 微观模拟完成后，工作流可以读取结构化结果，并通过明确的数据映射传给下游节点。
4. 任一节点失败时，其依赖节点不得继续执行；用户修正后可以从指定节点重新运行。
5. 上游输入或输出变化后，原执行记录和结果保留，受影响的下游节点显示已过期。
6. 用户可以从结果追溯到工作流版本、节点输入、上游结果、网格和求解器版本。

### 7.2 TIM 标准算例

1. 用户创建长方体基体，选择一种颗粒预设，设置尺寸、分布、最小间隙和取向。
2. 系统能够识别颗粒越界、重叠、接触或间隙不可网格化，并阻止提交。
3. 用户设置基体热导率、填料热导率、界面热阻、导热方向及冷热端温度。
4. 系统生成网格和算法输入，提交 Forge FVM V1 并显示作业状态。
5. 计算完成后展示指定方向有效热导率和实际填充率，并可查看原始结果文件。
6. 若算例包含温度场输出，系统可显示三维云图和切面。

### 7.3 流动标准算例

1. 用户创建简单圆管或受支持的变径流道，并确认入口和出口位置。
2. 用户设置密度、广义牛顿模型及参数、入口出口条件、壁面条件和生产温度。
3. 系统对不支持的多相、自由液面、可压缩、湍流或流固耦合设置进行阻止或提示。
4. 系统生成网格和算法输入，提交 Forge FVM V1 并显示作业状态。
5. 计算完成后展示压降、出口流速和体积流量。
6. 系统显示压力场和速度场三维云图及切面，并保留原始结果文件。

### 7.4 追溯与复现

1. 用户从“作业与结果”页面可以查看当次节点输入、引用的微观结果、几何、网格和求解器版本。
2. 用户复制历史算例并重新提交时，系统不会修改原作业和原结果。
3. 输入或算法版本发生变化时，新作业与旧作业具有可区分的版本记录。

## 8. 结果文件与可视化

### 8.1 当前结论

现有 Forge FVM V1 算法说明只定义了输出内容和展示形式，没有给出结果文件扩展名、字段结构、网格拓扑、坐标系或单位存储方式。因此，当前不能认定 Forge FVM 已采用 VTK、HDF5、CGNS 或其他具体格式。实际格式必须以算法团队提供的成功算例和文件规范为准。

### 8.2 建议的文件分层

| 结果类型 | 建议格式 | 系统处理方式 |
| --- | --- | --- |
| 工作流与结果清单 | JSON | 保存节点、输入快照、算法版本、文件索引、单位和来源等元数据 |
| 标量结果 | JSON；按需导出 CSV | 用于有效热导率、填充率、压降、出口流速和体积流量等结果展示 |
| 微观轨迹 | 保留现有微观模拟系统的原生格式 | 常见格式包括 LAMMPS dump、DCD、XTC、TRR、TNG 和 XYZ；V1 不新增一套轨迹格式 |
| 三维网格与场结果 | 优先评估 VTK XML 的 `.vtu`；并行分块可用 `.pvtu` | 适合保存非结构网格及温度、压力、速度等点数据或单元数据，并便于科学可视化工具读取 |
| 大规模场结果 | 评估 XDMF `.xdmf` + HDF5 `.h5` | XDMF 描述网格和场数据，HDF5 保存大规模数组；适合文件较大或需要分层存储的情况 |
| CFD 交换文件 | 若 Forge FVM 已支持，可保留 CGNS `.cgns` | CGNS 适合 CFD 网格与流场交换，但不应在算法尚未支持时强制新增 |
| 日志 | UTF-8 文本 `.log` 或 `.txt` | 用于在线查看、错误诊断和下载 |
| 求解器原始结果 | 原格式保留 | 作为归档和复现依据；通过结果适配器转换出网页展示所需数据 |

格式选择参考：[LAMMPS 输出格式](https://docs.lammps.org/dump.html)、[GROMACS 文件格式](https://manual.gromacs.org/documentation/2025.3/reference-manual/file-formats.html)、[VTK XML 文件格式](https://docs.vtk.org/en/v9.6.1/vtk_file_formats/vtkxml_file_format.html)、[XDMF 数据模型与格式](https://www.xdmf.org/index.php/XDMF_Model_and_Format.html)、[HDF5](https://www.hdfgroup.org/solutions/hdf5/) 和 [CGNS](https://cgns.org/index.html)。

### 8.3 可视化要求

- **需要在系统中直接查看：**有效热导率、填充率、压降、出口流速和体积流量等标量结果，以及温度场、压力场和速度场的三维云图、切面和图例。
- **复用已有能力：**微观结构和原子轨迹继续由系统现有微观模拟查看能力处理，工作流只负责跳转、引用或嵌入其结果。
- **不要求直接预览所有文件：**日志支持文本查看；求解器原始文件、HDF5、CGNS 等文件可以只提供下载，不建设通用文件浏览器。
- **原始文件与展示文件并存：**网页展示使用解析或转换后的数据，不能覆盖或替代求解器原始结果。
- **格式确认原则：**先取得 Forge FVM 真实结果样例，再在 `.vtu` 与 XDMF + HDF5 之间选择默认可视化交换格式，不在当前阶段强制定案。

# 任务管理页

更新日期：2026-11-10。

## 页面与导航

主菜单“作业与结果”改为“任务管理”，列表入口为`/tasks`。旧`/multiscale/runs`无工作流参数时也进入任务列表；带工作流和运行参数时仍打开指定报告。

沿用当前全局导航与品牌，在主区按参考图提供搜索与筛选、四个状态统计、纵向任务卡片和真实分页。

## 任务类型与数据

- **微观模拟**：独立微观任务演示记录，以及跨尺度工作流中已提交的微观物性计算节点。
- **跨尺度模型**：每次工作流执行对应一条任务记录，可区分同一工作流的多次执行。
- 独立微观任务当前未连接已有微观任务服务，页面标记原型演示；工作流执行读取本机已有记录，不编造新的求解结果。

## 列表交互

1. 支持任务名称/编号搜索、任务类型筛选和状态筛选。
2. 总任务数、运行中、已完成、失败四项统计按当前搜索与类型计算，点击统计可切换状态。
3. 每条记录显示任务名称、编号、状态、任务类型、物性或算法标签、提交时间、耗时、任务来源，以及适用时的进度或问题原因。
4. “查看参数”展开只读参数，按记录保留展开状态。
5. 跨尺度任务的查看与详情按钮直接进入对应执行工作台，展示计算建模、节点状态与计算任务列表；报告从工作台进入。微观任务仍打开详情与日志。
6. 移除按钮二次确认，仅从列表隐藏记录；不删除工作流、日志、快照，不取消计算。隐藏状态本机保存，可通过“恢复已移除任务”恢复。
7. 支持每页5/10/20条、上一页/下一页及筛选无匹配状态。
8. 当前工作流运行状态变化时刷新列表和统计，保留搜索与筛选。

## 实现与验证

页面模块：`prototype/src/features/tasks/`；样式：`prototype/src/styles/task-manager.css`。

验收覆盖两类任务区分、搜索与类型/状态组合筛选、统计切换、参数展开、分页、日志详情、跨尺度报告入口和可恢复移除。

## 跨尺度任务示例与编辑范围

内置四条独立演示任务：挤出模拟运行中、TIM 导热节点阻塞、挤出模拟部分完成、TIM 导热全部完成。示例保留初始设置快照与关联建模，状态不会仅因查看而自动推进。

执行任务的依赖结构固定，已完成节点输入与结果只读；未完成节点可调整参数，阻塞节点可处理后重试或继续运行。完成节点不重复计算。模型旋转、缩放与查看始终可用。打开关联建模可以复用、修改后提交新任务，不改写历史快照。

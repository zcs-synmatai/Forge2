# 模拟算法与建模输入

更新日期：2026-11-10。本文件更新当前原型的算法分类及输入表单，以此替代此前新建任务提供四种应用类型的说明。后续各算法的交互要求分别在对应章节扩展。

## 1. 分类与兼容

列表筛选、表头、新建任务及建模设置统一使用“模拟算法”，提供：

1. 挤出模拟：初始化四段连续管路，整体共用一种材料。
2. TIM 导热：初始化长方体基底及一种填料。
3. 通用示例：新建时无初始模型，保留建模工具和基础工作流节点。

旧“流动”“通用”“简单圆管”归入通用示例展示，已有圆管模型和参数不强制替换。V1归档保持原状。

## 2. 挤出模拟

保留圆柱、圆锥过渡段、圆柱、圆锥过渡段的连续几何，以及各段长度、入口/出口半径联动。几何尺寸在右侧“四段几何尺寸”中编辑。

### 整体材料物性

| 参数 | 原型单位 | 规则 |
| --- | --- | --- |
| 密度 | kg/m³ | 有限正数 |
| 黏度 | Pa·s | 有限正数，当前为标量输入 |
| 热导率 | W/(m·K) | 有限正数 |
| 比热 | J/(kg·K) | 有限正数 |

初始化值仅为演示参数，允许修改，不改写材料库数据。真实流变模型与参数接口后续另行确认，不将当前标量黏度表单等同于已接入非牛顿模型。

### 边界条件

| 边界 | 类型 | 输入及规则 |
| --- | --- | --- |
| 入口 | 质量流量 | g/s，正数 |
| 入口 | 速度 | m/s，正数 |
| 入口 | 压力 | MPa，有限数值，表压 |
| 出口 | 压力出口 | 默认；MPa，有限数值，表压；一般无需更改 |
| 出口 | 质量流量出口 | g/s，正数 |

入口三选一，只显示并启用一种输入。出口二选一。切换类型保留此前输入，整理给算法的边界对象仅包含当前类型、当前数值及单位，不同时提供互相冲突的入口条件。

上述单位为当前原型的界面约定；真实算法若使用其他单位，应在接口适配层转换。当前不提交真实求解任务。

## 3. TIM 导热

| 分组 | 输入 | 规则 |
| --- | --- | --- |
| 几何与颗粒 | 长方体长度、宽度、高度 | mm，可调，更新可视化比例 |
| 几何与颗粒 | 各填料结构的颗粒预设 | 球状/片状固定预设，仅选择，不自定义单颗粒尺寸 |
| 几何与颗粒 | 均一/随机分布 | 二选一；随机分布保存种子，相同种子产生相同示意排布 |
| 几何与颗粒 | 颗粒最小间隙 | mm，明确说明任意两颗粒之间应保留的最小间隔 |
| 几何与颗粒 | 柱体颗粒轴向 | 当前不设置 |
| 热物性输入 | 基体热导率、填料热导率 | W/(m·K)，正数 |
| 热物性输入 | 基体–填料界面热阻 | m²·K/W，非负数 |
| 温度边界 | 计算导热方向 | X/Y/Z，用户选择 |
| 温度边界 | 热端、冷端温度 | °C，用户输入；热端高于冷端 |
| 温度边界 | 侧面边界 | 固定绝热，只读展示 |

具体颗粒预设尺寸尚未由本轮需求给出，原型使用既有示意，不虚构正式算法的尺寸清单。真实颗粒几何生成及最小间隙检验仍待算法服务接入。

## 4. 保存、检验与执行

- 编辑后使用“保存参数”，输入、形状与分布保存在当前任务中；刷新保留。
- 修改使当前检验失效，并使相关未完成下游重新排队；已完成节点继续按既有规则锁定。
- 挤出新增四项物性及当前激活边界的完整性、数值检验；不检验未启用的替代边界值。
- 每次提交整理对应的`algorithmInput`：挤出包含整体材料、几何和互斥边界，TIM包含长方体、颗粒预设/分布、热物性与绝热边界。
- 历史执行快照保持原状；旧挤出草稿首次打开补齐缺失的演示字段，不覆盖已填写字段。

## 材料管理中的关键物性

关键物性按当前模拟算法筛选：挤出模拟为密度（kg/m³）、黏度（Pa·s）、热导率（W/(m·K)）、比热（J/(kg·K)）；TIM 导热中基体与填料均设置各自的热导率。界面热阻与温度边界仍属于建模设置，不属于单一材料物性。通用示例保留 tg、tc、CTE。

每种物性独立保存 MD、DFT、手动输入配置。手动值必须为大于零的有效数值，应用后同步到算法材料输入；MD、DFT 仅保存计算配置，不伪造求解数值。旧的属性配置保留在数据中，但不会出现在不匹配算法的选项中。


## 工作台布局与统一设置入口

计算建模在左、计算依赖图在右；中间分隔线支持拖动，也支持方向键调整，比例限制在 30%–70%，并在本机记忆。调整后工作流自动适应画布；窄屏采用上下布局。工作流全屏与恢复继续自动适应画布。

移除右侧常驻参数栏。几何设置负责尺寸与颗粒分布；材料管理负责结构、材料指派及关键物性；算法设置负责算法、模型名称、界面热阻和温度或流动边界。相同设置只保留一个入口，颗粒形貌统一放在材料管理中。

源建模页面不再单列可复用说明，最近任务状态与查看入口并入顶部操作栏。执行任务继续显示任务进度与快照信息，已完成节点的设置入口不可编辑。

## 挤出管段的截面与增删

几何设置的结构尺寸列表支持添加管段；添加时可选择管路最前端、指定管段之前或末端。删除全部管段后仍保留添加入口。新管段默认继承末端截面及出口尺寸，所有管段共用流体材料，不增加材料计算分支。

每段均设置长度和截面形状：圆形设置入口半径、出口半径；方形设置入口长、入口宽、出口长、出口宽。尺寸均须大于零。保存后更新三维模型、坐标范围和算法几何输入，沿 X 轴依次排列；同类截面相邻接口同步尺寸，不同截面分别保留尺寸。

## 材料微观建模与计算配置的统一入口

材料管理的每个材料条目提供微观建模入口，打开二维分子式与三维预览弹窗。应用模型先写入当前材料草稿，确认材料管理后才保存到对应微观建模节点；取消材料管理则丢弃草稿，不修改材料库原始分子。

微观物性计算节点的配置与材料管理中的关键物性参数共用表单及数据，支持按算法选择物性，并分别保存 MD、DFT、手动输入设置。任一入口保存后同步另一入口，更新材料计算节点及相关下游的状态。节点配置不再提供重复的计算温度、计算步数与任务引用表单。MD 检查链数、温度范围、帧与间隔；DFT 检查选项及整数参数；手动输入检查有效正数。已完成节点只读。

# 建模复用与任务快照

更新日期：2026-11-10。本规则覆盖旧版“执行后锁定整个建模配置、需要复制任务才能再次计算”的限制。

## 1. 产品对象

| 对象 | 职责 | 修改规则 |
| --- | --- | --- |
| 建模与工作流定义 | 可复用的几何、结构、材料、物性、边界、节点和连接配置 | 可持续编辑，修改后重新检验，再次提交 |
| 跨尺度模拟任务 | 基于一次提交创建的独立运行实例 | 每次提交生成一个任务ID，关联源定义及提交版本 |
| 提交快照 | 该任务创建时的完整建模与工作流设置 | 只读，不随后续定义修改而改变 |
| 任务执行设置与输入 | 任务运行期间的节点设置、提交批次及各次实际输入 | 未完成节点可按既有规则处理，完成节点锁定；不回写源定义 |

主列表标题为“跨尺度建模与工作流管理”，新建入口为“新建建模”。任务管理中的跨尺度任务类型统一为“跨尺度模拟”，另一类型仍为“微观模拟”。

## 2. 使用流程

1. 创建建模与工作流，选择算法并配置模型、物性和边界。
2. 提交计算任务时检验当前定义，生成独立任务及完整快照，进入该任务的执行页。
3. 任务关联源建模ID、提交时名称、配置版本和算法。提交快照保存节点参数、几何、结构、材料、物性、边界、节点及依赖关系。
4. 可从任务执行页或任务管理详情“打开关联建模”，调整参数后再次提交。
5. 再次提交新建任务，不覆盖上一次任务，不复用上次进度或将它自动重置。
6. 同一建模可关联多个任务；原型在页面未刷新的情况下可并行推进多个本地演示任务。
7. 任务详情可查看原始提交快照、提交版本和日志，分别进入“查看本次任务”或“打开关联建模”。

## 3. 定义与任务隔离

- 定义页不因历史任务完成而锁定，节点显示配置检验状态。
- 执行页使用独立节点与参数副本，展示该任务的进度与状态；不会用另一个任务的状态覆盖它。
- 在执行页修改未完成节点，保存的是该任务的执行设置和实际输入，不修改源定义、其他任务或原始提交快照。
- 完成节点只读；继续部分执行或重试阻塞任务仍属于同一任务，保留完成结果。
- 如需将新的参数组合重复计算，回到源定义修改并提交新任务。
- 每个任务独立保存当前执行设置，刷新后可恢复查看或继续；本地演示不等同于真实后台调度。

## 4. 数据关联

运行记录增加`definitionRef`（建模ID、提交时名称、版本、算法），`snapshot`保存只读提交设置；`workingDefinition`保存任务自身的执行配置。节点`completedInput`、`attemptHistory`及批次快照保留实际输入追溯。

源定义和任务共享历史记录索引，但几何、材料、节点参数与依赖对象相互独立。任务列表按“建模ID＋任务ID”区分同一建模的多次执行。

## 5. 验收

- 建模A以热端80°C提交任务1，随后改为95°C提交任务2；两任务关联相同建模ID，快照温度分别为80°C、95°C。
- 任务1完成后，建模A仍可编辑并提交任务3。
- 修改源定义不影响仍在运行的任务；修改某任务未完成节点不影响源定义或另一任务。
- 任务管理中每次提交都有独立跨尺度模拟记录，可查看当次快照和源建模。
- 原始历史快照不迁移改写，已有V1归档不变。

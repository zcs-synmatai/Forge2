# Forge2

SynMatAI 跨尺度建模与工作流管理交互原型。

- 原型源码：`prototype/`
- 需求文档：`docs/`
- 本地启动：在 `prototype/` 运行 `npm start`
- 静态构建：在 `prototype/` 运行 `npm run build`
- GitHub Pages：https://zcs-synmatai.github.io/Forge2/

推送 main 后由 GitHub Actions 自动构建并部署。演示登录在 `prototype/config/demo-auth.json` 配置，仅用于交互演示，静态公开站点不提供真实权限保护。

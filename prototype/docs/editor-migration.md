# V1 工作台迁移记录

本页记录已保留的工作流编辑 V1。当前编辑入口已改为物理建模，详见 physical-model.md；原画布在“演示说明 → 工作流编辑 V1”中保留。

当前版最新修正：页面区域内容沿用 V1，仅模型配置在上、工作流画布在下。宏观预览新增 composite-preview.js 的方块 / 填料演示，支持画布颗粒拾取、材料组高亮和快捷菜单；微观建模在分子示意弹窗中完成，不通过此前试验三栏视图。V1 快照不修改。

参考实现来自 D:\Agent4\prototype\SynMatAI，代码在本项目 prototype 独立维护，无运行时外部目录依赖。

当前节点模型为微观模拟 → 宏观建模 → 计算调度 → 结果呈现。只有这四种节点类型，按相邻阶段正向连接；同阶段、反向、跨阶段与循环不允许。多个同类节点可以并存。

原 TIM 六节点定义已迁移：
- 微观任务作为微观模拟节点；原提取配置随微观引用保留。
- TIM / 流动与几何参数合入宏观建模；原物性映射配置保存在模型 binding 中，后续内部映射表单可继续扩展。
- 宏观模型下游新增独立计算调度，再连接结果呈现。
- 原定义保存为 legacyDefinition，旧 runs 快照不改写。迁移后重新检查。
- 新宏观节点默认为通用模型；TIM 与流动是可切换案例，各案例参数独立保存。

保留原分栏布局。无限画布仅嵌入右上 dependency-panel 的矩形视口；Copilot 在左侧、模型与配置在下方常驻。无节点悬浮属性弹窗。画布仍使用源 FlowCanvasV2、FlowCanvasModel 的相机、拖动、多选、吸附、四侧端口、缩略图、定位与撤销重做。

canvas-runtime 中的源样式和算法保留，本项目适配包括 ES 模块、embedded 模式、独立存储键、外部缩放接口、选中回调、尺寸观察与节点浮窗开关。画布镜头按新的四阶段键隔离，避免沿用旧六节点镜头。

原型可演示参数保存、失效传播、方向校验、依赖执行、运行快照、报告状态与作业跳转。调度资源和重试为配置原型，未接入真实队列或算法。几何预览为 Canvas 示意，不是网格器或真实求解器。

画布左下已启用源缩放工具条：缩小、恢复 100%、放大、适应、当前节点和自动布局；嵌入模式自动布局后保持全部节点适配，不再强制放大至 80%。

微观节点增加 molecule.js 的结构草稿、molecule-preview.js 的 Canvas 球棍预览和 molecule-editor.js 的修改面板。支持丁烷、乙醇、苯示例及原子/键编辑，取消不落盘、应用才保存到节点 params.molecule，并使用现有失效传播与定义撤销。预览未连接真实任务结构文件，结构校验仅覆盖坐标、索引及重复项，不构成化学有效性检查。

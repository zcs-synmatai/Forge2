# 点胶报告页面说明

更新日期：2026-11-10。

当前工作台运行条中的“查看本次作业”改为“查看报告”，上方建模面板标题改为“计算建模”。节点阶段及内部类型不改动，V1归档保持原状。

报告页依据 `case/点胶仿真报告V1.pptx` 的三页内容整理：

- 第1页：仿真目的、材料密度、7组转速/黏度数据；内嵌 `Workbook1.xlsx` 提供Herschel–Bulkley拟合参数、R²、RMSE及剪切速率换算系数。
- 第2页：实验几何图，保留原图尺寸标注和流动方向。
- 第3页：两个压力工况下的出口直径扫描、黏度倍率扫描及原报告结论。

页面提供目录、概览、几何工况、黏度拟合、出口直径影响、黏度敏感性及结论。压力切换仅切换原报告数据，不调用计算服务。0.4MPa、0.40mm对应仿真值原文件为“/”，页面按缺失数据处理，不补齐。

拟合曲线使用原始内嵌工作表缓存参数绘制，不重新拟合。所有表格中的出胶量单位为g/s，不改写为线速度。0.48–0.50mm范围按原报告结论呈现，不宣称各工况下误差均最小。

为避免误关联，页面标注“参考报告展示”。当前工作流名称、运行状态、日志和输入快照与参考报告数据分开呈现；运行未完成时明确提示本次报告尚未就绪。支持下载原PPTX和浏览器打印/保存PDF，不将源文件伪装为求解器输出。

实现位置：`src/features/reports/`、`src/styles/report.css`。原报告未被修改。

# 独立材料窗口与物理建模试验记录

最新布局更正：主编辑页已恢复 V1 的区域内容，仅将宏观建模 / 节点配置放在右侧上方，工作流画布放在其下方，Copilot 留在左侧。下述三栏物理建模主视图不再作为编辑页入口，代码及独立草稿保留；材料子路由仍作为单独的辅助原型页面保留。

## 版本入口

- 当前入口保持 /multiscale/workflows/:workflowId/edit，从工作流列表进入。
- 当前主编辑页同时保留上方模型配置与下方工作流画布。
- 选择模型材料后点击“进入材料建模”，进入 /multiscale/workflows/:workflowId/edit/materials/:materialId。材料窗口可直接刷新和返回。
- 原编辑页面保留为“演示说明 → 工作流编辑 V1”，路由 /demo/workflow-editor-v1?workflowId=...，保留四阶段无限画布、Copilot、节点配置及原演示功能。

## 保留的试验交互

物理建模：左侧模型结构（几何、材料、物理场、边界条件、网格），中间几何视图和模型材料列表，右侧当前配置。可通过几何视图上方的区域标签、结构树或材料列表选择材料，右侧提供“进入材料建模”。区域选择是显式标签交互，尚未实现 CAD 几何拾取。

材料建模：保留物理模型与材料的上下文，展示当前材料的结构视图。支持材料属性、分子结构和微观模拟引用配置，分子编辑复用现有修改面板。保存后更新主模型中的对应材料，返回后保留选择。未配置结构的材料展示创建入口，不伪造真实结构。

空白模型可选择 TIM 或简单圆管案例创建示例几何。可以添加材料、修改区域绑定和物性。模型检查覆盖基础输入完整性、几何尺寸、材料区域及部分案例参数；不构成真实物理或网格校验。计算设置只保存本地演示配置，未接入调度服务。

## 数据隔离

- 原数据 forge-editor-v1 不由试验三栏视图和材料子窗口写入；当前已恢复的主编辑页仍使用该工作流草稿。
- V1 首次从原草稿初始化，后续使用 forge-demo-editor-v1，画布使用 forge-demo-canvas-v1。
- 新版模型使用 forge-physical-model-v2，模型包含独立的 geometry、materials、scheduler、revision 和 history。首次以原案例参数初始化，不改写原定义或历史执行快照。
- V1 代码保存在 features/editor-v1，源品牌和页面样式保存在 styles/editor-v1；新版位于 features/physical-model。

## 验证

覆盖案例初始化、旧定义不变、材料回传与检查失效、未绑定区域、通用空模型、材料窗口路由及 V1 / 当前存储隔离。浏览器验证了材料选择进入、保存返回、V1 子菜单切换与参数隔离。

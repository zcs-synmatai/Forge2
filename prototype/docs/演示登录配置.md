# 演示登录配置

## 使用与配置

登录配置文件：[`config/demo-auth.json`](../config/demo-auth.json)。直接编辑该JSON文件，无需后端或构建工具；保存后刷新网页生效。

默认演示账号：

| 账号 | 密码 | 显示名称 |
| --- | --- | --- |
| demo | SynMatAI2026! | 演示用户 |

请仅使用专门的演示密码，不填写真实业务系统、个人或其他平台的密码。

```json
{
  "enabled": true,
  "platformName": "材料研发平台",
  "sessionHours": 8,
  "sessionVersion": "2026-11-10-v1",
  "users": [
    {
      "username": "demo",
      "password": "SynMatAI2026!",
      "displayName": "演示用户"
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| enabled | true启用演示登录；false关闭门槛、直接进入原型 |
| platformName | 登录页标题中的平台名称 |
| sessionHours | 单次登录有效小时数，大于0且不超过168；默认8小时 |
| sessionVersion | 会话版本。修改密码后同时改此值，使旧登录状态在刷新时失效 |
| users | 演示账号列表，可添加多个账号；用户名不能重复或含首尾空格 |
| username / password | 登录账号与密码；密码区分大小写，不自动去掉空格 |
| displayName | 登录后侧栏底部显示的名称 |

登录成功后返回用户原先打开的任务或报告地址，不强制回列表。侧栏底部的退出按钮会清除登录状态，不清除任务草稿和历史演示数据。登录状态保存于sessionStorage，刷新可保留；关闭标签页或超过有效期后需要重新登录。不提供“记住密码”，也不把密码写入会话存储。

配置缺失、格式错误或浏览器不允许保存会话时，不开放页面，显示错误及重试入口。

## 静态部署

将`config/`、`src/`、`public/assets/`对应的静态资源和入口文件一并部署。当前开发服务将`public/assets`映射到`/assets`，发布时也应按此目录结构放置资源。登录本身不需要Node服务、接口或数据库；本地预览请通过HTTP启动，不直接双击HTML。

原型当前使用以站点根路径开头的资源地址与History路由，静态托管需配置单页应用入口回退。GitHub Pages项目子目录发布还需处理路径前缀和深层路由回退；本次登录功能未改造原有部署路径。不应把“登录可用”等同于“已经完成所有GitHub Pages部署适配”。

## 能力边界

这是纯JavaScript的演示访问门槛，用来呈现登录体验，不是真实身份认证或权限控制。公开仓库或公开静态站点中，配置文件、演示密码、页面脚本、PPTX与其他资源均可被读取，知道资源地址的人也可能绕过登录直接访问。

不要通过此功能保护保密材料、个人信息或真实业务数据。若后续需要真正限制访问，应由托管平台访问控制、网关或服务端认证保护站点和静态资源。
